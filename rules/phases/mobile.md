# Mobile phase

Load only the selected Flutter behavior pack and generate original application source
under target `apps/mobile/`. Use approved design semantics and API contracts while
adapting interactions to Android and iOS conventions. Require typed network boundaries,
secure storage, lifecycle and offline states, accessibility, localization, focused
tests, deterministic structure evidence, and truthful platform release evidence.
For requirement-backed realtime, use the Flutter realtime skill and produce
`.ai/evidence/realtime/mobile.json`. Require typed events, secure ticket authentication, bounded
reconnect, cursor resync, gap/deduplication handling, offline/push behavior, Android/iOS lifecycle
cleanup, integration tests, and accessible announcements.
