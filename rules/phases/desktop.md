# Desktop phase

Build the selected PySide6 application in `apps/desktop`. Keep domain behavior outside widgets,
use argument arrays rather than shell interpolation, package resources inside the Python package,
and register deterministic lint, type, test, package, and installation checks. For floating desktop
companions, verify transparency, frameless and always-on-top behavior, screen-bound movement,
dragging, explicit exit controls, bounded CPU usage, and truthful Wayland limitations.
