# Run one-shot delivery

Use the deterministic CLI for initialization, reconciliation, phase readiness,
checkpoints, command execution, gates, commits, and pushes. Dispatch agentic blueprint
nodes through the selected adapter; do not simulate their outputs.

The lifecycle is sequential: requirements/contracts, design/HTML approval, frontend,
backend, integration, testing/security, then delivery. Load base behavior plus exactly
one selected frontend and backend pack. Application source is created only in the
user's target monorepo.

Read `references/lifecycle.md` before an executing run or recovery.
